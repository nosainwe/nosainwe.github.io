# Nosa Peter Inwe — portfolio

Static GitHub Pages website. Open index.html or serve this directory with python -m http.server 8765. No build step or runtime dependencies.

## Updating certificates

The certificates page is static HTML so every credential remains visible without JavaScript. certifications.js adds search and topic filtering. Certificate documents are stored in certificates/. certificates.json holds the catalogue metadata; keep it and certifications.html in sync when adding credentials.
